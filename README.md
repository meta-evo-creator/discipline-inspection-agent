# Discipline Inspection Agent ⚔️

**China's first and only known AI agent for party discipline inspection analysis.**

Built on OpenClaw framework: 8-agent pipeline with 6-module analytical methodology.

## Architecture

Scope → Search-RG(rg wiki) → Search-PKULaw(version verify) → Audit(evidence chain) → Analyze(6 modules) → Draft → Review → Revise → Publish

## Methodology v2.2

Core: Two-factor analysis (violation + accountability) + Enhancement modules:
M2(Lemon Market) · M4(4-Layer Attribution) · M6(Defense Audit) · M7(Attribution Calibration) · M8(Just Culture) · M9(Scapegoat Audit)

## Setup

Clone into OpenClaw skills directory. Replace `$WORKSPACE` in agent paths with your OpenClaw workspace.
